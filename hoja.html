Acciones · lo que el robot hace

avanzar(); Da un paso hacia donde estás mirando.
girarDerecha(); Giras a la derecha. No te mueves de casilla.
girarIzquierda(); Giras a la izquierda. No te mueves de casilla.

Preguntas · contestan sí o no

caminoLibre() ¿Está libre la casilla de enfrente?
caminoLibreDerecha() ¿Está libre la casilla de tu derecha?
Las preguntas no van solas: viven dentro de un si o de un mientras.

Las reglas

  • El robot siempre empieza mirando al este (a la derecha).
  • Escribes el programa completo y lo sueltas. No se maneja con las flechas del teclado.
  • Gana el programa más corto, no el más rápido. Cada nivel te dice en cuántos bloques se puede. 
repetir (6) {   <- 1
  avanzar();    <- 2
}               <- no cuenta

Cuenta 1 por cada instrucción y 1 por cada estructura. Las llaves de cierre no cuentan. Este programa son 2 bloques.

Estructuras · cómo se agrupa

repetir — hace lo de adentro el número de veces que le pongas. 
repetir (4) {
  avanzar();
}
mientras — repite mientras la respuesta siga siendo sí. 
mientras (caminoLibre()) {
  avanzar();
}
si / sino — una cosa u otra, según la respuesta. 
si (caminoLibre()) {
  avanzar();
} sino {
  girarDerecha();
}
repetirHastaLaMeta — repite hasta pisar la meta. Se desbloquea en el bonus. 
repetirHastaLaMeta {
  avanzar();
}
